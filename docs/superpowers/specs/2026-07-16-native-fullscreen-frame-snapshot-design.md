# Native Fullscreen Frame Snapshot

## Goal

验证并完善 PR #4，使查看器窗口无论在进入原生全屏前或全屏期间如何切换标题栏显示状态，退出全屏后都恢复进入前的位置和大小。

## Scope

- 覆盖以下三个回归场景：
  - 隐藏标题栏进入并退出全屏。
  - 隐藏标题栏进入全屏，在全屏中切换为显示标题栏后退出。
  - 显示标题栏进入全屏，在全屏中切换为隐藏标题栏后退出。
- 覆盖进入全屏失败、重复准备全屏和成功退出后的状态清理。
- 不增加 UI 自动化，不改变临时桌面全屏行为，也不扩展到显示器热插拔处理。

## Design

`ViewerWindow` 在首次准备进入原生全屏时保存一个私有快照，快照同时包含进入前的 `styleMask` 和窗口 `frame`。重复准备不会覆盖第一次快照。

正常退出时，窗口采用用户当前标题栏偏好对应的样式，但恢复快照中的原始 `frame`。这避免根据标题栏高度进行人工加减，从而消除窗口上移或上下拉伸。快照通过单一恢复入口消费并清空，避免样式和 frame 状态分别清理而产生不同步。

进入全屏失败时，恢复快照中的原始样式和 frame，然后清空快照。`WindowManager` 仍负责标题栏外观、圆角和固定窗口状态等外围处理。

## Testing

测试直接创建 `ViewerWindow`，记录原始 frame，准备进入全屏，再模拟 AppKit 改变 frame，并以目标标题栏样式完成退出恢复。三个核心测试分别断言：

- 恢复后的 frame 与进入全屏前完全相等。
- 恢复后的样式符合退出时的标题栏偏好。
- 快照已经清理，后续失败恢复调用不会再次改变窗口。

补充测试验证进入失败会恢复 frame 和原始样式，以及重复准备仍保留第一次捕获的 frame。
