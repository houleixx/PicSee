# 滚轮和捏合的光标锚定缩放

## 行为

- 鼠标滚轮缩放、触控板捏合缩放使用事件的 `locationInWindow`，转换到图片画布的视口坐标。捏合使用事件光标位置，不推测触控板双指中心。
- 调整缩放后的平移量，使光标下的同一源图片位置保持在原来的视口位置。保留原来的平移约束、缩放上下限及回到适合窗口时居中的规则；边缘约束优先于锚点固定。
- 工具栏和键盘请求仍默认使用视口中心。双击、全屏、适合窗口、原始尺寸及触控板双指滚动平移的行为不变。
- 修复缩放过程中下一帧几何模型遗漏旋转角度的问题，确保 90°/270° 旋转后的适合比例和边缘限制正确。

## 验证

- 新增几何测试覆盖四种旋转角度、放大与缩小、缩放上下限、平移边缘和适合窗口复位。
- 新增 AppKit 交互测试覆盖嵌套画布的窗口坐标转换、滚轮与捏合、工具栏中心锚点和触控板平移。
- 专项测试包含原有缩放动画、双击复位和几何回归，均通过；新增测试共 25 组参数场景。

- 全部桌面回归 137 项通过（101 项 XCTest、36 项 Swift Testing），包括 OCR、截图、窗口和新增光标缩放测试；本次全量合计 429 项通过。
