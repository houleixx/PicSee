# 图片加载、编辑内存与更新可靠性

## 实现范围

- 正式应用默认后台加载，解码工作串行执行，取消任务在进入解码器前检查；完成回到主线程时验证请求编号。同步策略仅供模型测试显式注入。
- 首张图加载时立即创建可关闭的窗口，加载完成后按原尺寸规则调整；已移动／缩放、固定窗口或全屏时不调整。窗口标题在已发布状态提交后读取。
- Finder 查询与目录快照扫描在后台执行，早期切图按键排队。外部换图失败保留旧会话；删除后的候选图与撤销恢复也使用后台加载。
- 图片元数据为不可变值，日期与闪光灯文字在展示时本地化。文件大小、像素尺寸和透明度随加载取得，视图刷新不再重复读取文件或扫描全图透明像素。
- OCR 调度从画布提取为 `ImageTextRecognizer`，原子设置图像与 URL，120 毫秒防抖，取消与版本号共同阻止旧结果提交。Vision 工作串行执行。
- 无旋转编辑复用 CGImage 像素，禁用该包装图像的 AppKit 显示缓存；CG-backed 图像的尺寸从原 CGImage 读取，避免 Retina snapshot 表示的显示倍率污染像素尺寸。马赛克按需生成；分配失败使用不透明遮盖。渲染分配前检查尺寸、整数溢出和内存预算。
- 更新在退出前验证并准备副本；安装事务保留原应用，失败恢复；不移除 quarantine。签名要求同一 Developer ID 团队及系统验证，Ad-hoc 版本需手动安装。
- 新增 PR／push 检查并作为发布前置条件；桌面依赖的测试有明确分组。

## 验证方式

`ImageLoadingTests` 控制慢加载与迟到结果，覆盖启动期间切图、连续翻页、外部打开成功／失败、元数据缓存、删除撤销和幻灯片加载间隔。

`UpdateInstallerTests` 在临时目录执行实际安装事务，只替换外部系统命令。覆盖签名拒绝、替换失败、启动失败与成功路径，检查原应用、状态文件及备份清理；响应测试覆盖 HTTP 错误、非 HTTPS、空下载及截断。

`ImageTextRecognizerTests` 覆盖防抖取消与连续替换只启动一次。`ImageRenderBudgetTests` 覆盖非有限尺寸、非正尺寸、溢出及四通道分配预算。现有截图测试验证所有标注工具、旋转、采样及原像素输出。

图形与系统集成测试在正常 macOS 桌面环境运行；受限沙箱内无法创建 Core Image 输出、编译 Finder 字典或接收跨进程通知，不能将这些环境失败直接视为应用缺陷。

尚未测量大型 RAW、万张目录、网络卷和多进程总内存的实际基准；不据此声明具体速度提升比例。测试中的安装事务不替换用户的实际应用；真实 Developer ID、公证及 DMG 验证仍由发行工作流执行。
