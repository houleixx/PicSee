PicSee

Free & open source · No ads

Double-click to open. Close to quit.A lightweight, native macOS image viewer. Zoom, crop, annotate, and copy text with OCR. PicSee quits when you close the viewer window, with no extra steps.

  • Scroll to zoom · Drag to pan
  • Crop images · Annotate in place
  • Select and copy text with OCR
  • Browse with arrow keys
Download for macOS View source on GitHub
01

Scroll to zoom Drag to pan

Use the mouse wheel to zoom, then drag to pan around. Explore the details or take in the whole picture, whether you are viewing photos, long screenshots, or design mockups.

02

Select and crop Annotate in place

Select an area to crop and enter an exact width and height. Add arrows, shapes, or text, or pixelate sensitive details. Copy the result or save it as a PNG.

03

Select text with OCR Copy instantly

Recognize text in images with OCR, drag to select it, and press ⌘C to copy. Extract text from screenshots or scanned documents without retyping.

04

Browse with arrow keys Follow Finder order

Use the arrow keys to browse images in the same folder. With Automation permission granted and Finder’s sort order available, PicSee follows that order. Otherwise, it uses natural filename order.

05

Make it your default Double-click to open

Choose image formats in Settings to make PicSee their default app. Then just double-click an image in Finder to open it.

Supported image formats

JPEG .jpg, .jpeg PNG .png GIF .gif HEIC .heic TIFF .tif, .tiff BMP .bmp WebP .webp RAW .dng, .cr2, .cr3, .nef, .arw, .raf, .rw2 AVIF .avif SVG .svg Icons .ico, .icns JPEG 2000 .jp2, .j2k, .jpf, .jpx Photoshop .psd, .psb TGA .tga DDS .dds OpenEXR .exr Radiance HDR .hdr JPEG XL .jxl

Full decoding of professional image formats depends on ImageIO support in your macOS version and the previews embedded in each file.
