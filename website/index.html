PicSee

免费开源 · 无广告

Finder 双击即开，看完即退。轻量、原生的 macOS 看图工具，支持图片缩放、裁剪标注与 OCR 文字识别复制。关闭看图窗口即退出，无需再手动结束应用。

  • 滚轮缩放 · 拖动平移
  • 图片裁剪 · 就地标注
  • OCR 选字复制
  • 方向键切图
下载 macOS 版 查看 GitHub 源码
01

滚轮缩放 拖动平移

在 Mac 上用鼠标滚轮缩放图片，放大后拖动平移。查看照片、长截图或设计稿时，既能看清细节，也能快速浏览全貌。

02

框选裁剪 就地标注

在当前图片中框选裁剪，输入宽高精确调整尺寸。添加箭头、形状和文字标注，或用马赛克遮住隐私；完成后直接复制或保存为 PNG。

03

OCR 选字 直接复制

通过 OCR 识别图片中的文字，拖动选中后按 ⌘C 即可复制。提取 Mac 截图或扫描文档中的文字，无需手动重新输入。

04

方向键切图 跟随 Finder 排序

用方向键浏览同一文件夹里的图片，连续看图更顺手。授权自动化权限且 Finder 排列可读取时，切图顺序跟随 Finder；否则按文件名自然排序。

05

设为默认 双击即开

在设置中选择图片格式，让 PicSee 成为默认打开方式。以后在 Finder 中双击图片，就能直接查看。

支持的图片格式

JPEG .jpg, .jpeg PNG .png GIF .gif HEIC .heic TIFF .tif, .tiff BMP .bmp WebP .webp RAW .dng, .cr2, .cr3, .nef, .arw, .raf, .rw2 AVIF .avif SVG .svg 图标 .ico, .icns JPEG 2000 .jp2, .j2k, .jpf, .jpx Photoshop .psd, .psb TGA .tga DDS .dds OpenEXR .exr Radiance HDR .hdr JPEG XL .jxl

专业格式的完整解码取决于当前 macOS 的 ImageIO 支持及文件内嵌预览。
